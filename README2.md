World Happiness Challenge Solution

How to Run:

1. Install the necessary libraries using the command:
	pip install pandas matplotlib
2. Run the Python script using the command:
	python solution.py
	
	
Results:
- The average happiness score by region is saved in average_happiness_by_region.csv.
- The top 10 and bottom 10 countries by GDP are saved in top_10_gdp.csv and bottom_10_gdp.csv.
- A scatter plot is saved as gdp_vs_happiness.png.
